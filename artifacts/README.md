# Contract ABIs

This folder contains JSON artifacts describing the interfaces (ABIs) of the CTF Exchange smart contracts.

- `CTFExchange.json` – the ABI for the core CTF exchange contract. This file is generated from the Solidity sources and can be used by clients to interact with the deployed exchange.
- `ConditionalTokens.json` – the ABI for the ConditionalTokens contract used for tokenized outcomes.

These files are committed for convenience. If you update or regenerate the smart contracts, please ensure the corresponding ABI JSON files are updated here as well.
