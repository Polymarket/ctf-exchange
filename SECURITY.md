# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this repository, please do not open a public issue. Instead, report it privately via a GitHub security advisory or by contacting the maintainers directly.

## Information to Provide

- The module or component affected (if known).
- A clear description of the issue and its impact.
- Steps to reproduce or a minimal proof-of-concept.
- Suggested remediation or mitigation if available.

## Disclosure Process

We will review and address reported issues as quickly as possible. Please allow time for a fix to be prepared before public disclosure.
